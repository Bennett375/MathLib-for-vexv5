# Mathlib

## What is Mathlib?

Mathlib is a comprehensive mathematics library for Vex V5. It relies on a custom, heavily optimized internal linear algebra engine, while still exposing a simple and compact API.

Mathlib supports a high level, simple, and easy to understand abstraction of various control algorithms, while still exposing the underlying operations for advanced use.

## Features:

* Matrices and Vectors of an arbitrary numeric type
* Highly optimized algorithms for Matrix operations
* Supports predefined and user-definable type conversions (e.g. Point -> Vector)
* Algebraic Solution Engine, supporting LU, QR, and Cholesky decomposition and solving
* Native Gaussian Class
* Custom Probability Engine
